The metadata are split into the following files:
- fmt.meta.txt: metadata associated with each fecal transplant
- samples.meta.txt: metadata associated with each sample
- triads.txt: this file lists "triads" of donor, pre-fmt, and post-fmt samples
- delta_t.txt: the number of days elapsed since the FMT for each sample

The columns of fmt.meta.txt are:
- txid = unique transplant ID
- date = date of FMT
- donor = donor ID
- recipient = recipient ID
- sample = donor sample ID
- route = route of transplant (nasogastric tube or colonoscopy)
- abx = whether antibiotics were taken before the FMT
- abx_time = number of days prior to FMT antibiotics were taken
- recurrence = recurrence of infection after FMT
- recurrence_date = date of recurrence after FMT
- success = FMT success
- recipient_first = ID of first sample collected from patient prior to FMT
- recipient_last = ID of last sample collected from patient prior to FMT
- timeline = IDs of post-FMT samples collected from patient (ordered by time)
- preservative = how the sample was stored
- immunosuppressants = whether immunosuppressants had been prescribed

The columns of samples.meta.txt are:
- sample = sample ID
- subject = subject ID
- date = visit date
- type = donor or recipient
- ssx_resolved = were symptoms resolved at time of visit?
- health = health score at time of visit
- freq = stool frequency at time of visit
- gids = metagenomic IDs associated with this sample
- depth = total depth of sequencing associated with this sample

The columns of triads.txt are:
- subject = recipient ID
- donor = donor ID
- pre_sample = pre-fmt sample ID
- donor_sample = donor sample ID
- post_samples = post-fmt sample IDs
- success = whether the FMT was successful
* Note: If > 1 pre-FMT sample was collected, this file lists the most recent one prior to FMT

The columns of delta_t.txt are:
- sample = sample ID
- delta_t = days elapsed since FMT
